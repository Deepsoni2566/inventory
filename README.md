# 📦 Hybrid Inventory Management System (DApp Powered)

A decentralized inventory management system built with Java Swing, MySQL, and Ethereum smart contracts.  
This hybrid DApp combines a user-friendly desktop interface with blockchain-backed audit logging to ensure data integrity and transparency.

---

## 🧾 Project Details

- **Project Title**: Hybrid Inventory Manager (Blockchain + SQL)
- **Version**: v1.0.0
- **Author**: Deep Soni
 **University**: University of East London
- **Repository**: [https://github.com/Deepsoni2566/inventory] 
                  (https://github.com/Deepsoni2566/inventory)

---

## ✨ Key Features

- ✅ **Decentralized Audit Logging** using Ethereum smart contracts
- 📊 **Product & Category Management** with blockchain-backed integrity
- 📤 **QR Code Generation** for every added product
- 📧 **Automated Daily Email Summaries** of stock and sales
- ⚠️ **Allergy Detection** from product descriptions using predefined keyword mapping
- 🎨 **Modern Pastel-Themed GUI** built with Java Swing and FlatLaf
- 🧠 **AI Assist Button** (ready for integration with GPT/OpenAI)
- 🛢️ **Hybrid Storage**: MySQL for data, Ethereum for events

| Layer        | Technology                          |
|--------------|--------------------------------------|
| Frontend     | Java Swing, FlatLaf                  |
| Backend      | Java, JDBC, Web3j                    |
| Database     | MySQL 8+                             |
| Blockchain   | Ethereum (Ganache / Testnet), Web3j  |
| Utilities    | ZXing (QR), JavaMail, Smart Contracts |

---

## 🛠 Prerequisites

- Java JDK 11 or above
- NetBeans or IntelliJ (non-Maven Java project)
- MySQL Server
- Ganache (local Ethereum blockchain)
- Required `.jar` files:
  - `web3j-core-<version>.jar`
  - `mysql-connector-java.jar`
  - `zxing-core.jar`, `zxing-javase.jar`
  - `flatlaf.jar`
  - `javax.mail.jar`
